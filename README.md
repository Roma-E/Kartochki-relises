# Карточки 🐶

Интервальное повторение карточек с формулами и питомцем.

## 📱 Android
**[Скачать APK (версия 0.2.6)](https://raw.githubusercontent.com/Roma-E/Kartochki-relises/main/apk/kartochki-0.2.6.apk)**

Открой файл на телефоне → «Установить». Если телефон спросит — разреши установку из этого источника.
Дальше приложение обновляется само: Настройки → «Уведомлять о новых версиях».

<sub>Бета для тестов: [0.2.6-beta.2](https://raw.githubusercontent.com/Roma-E/Kartochki-relises/main/apk/kartochki-0.2.6-beta.2.apk) — ставь, только если тестируешь.</sub>

## 🍏 iPhone
Открой в Safari сайт этого репозитория (Settings → Pages) → «Поделиться» → «На экран Домой».
